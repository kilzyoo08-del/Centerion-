# Виртуальное вычислительное ядро Centerion

## Что это
Первый слой собственной вычислительной среды Centerion: ограниченный планировщик задач, пул рабочих потоков, реестр разрешённых обработчиков, идентификаторы задач и контроль их состояний.

Это программный runtime уровня приложения, а не гипервизор и не создание новых физических CPU/GPU. Он использует ресурсы машины, на которой запущен.

## Безопасность
- Выполняются только обработчики, явно зарегистрированные разработчиком.
- Переданный пользователем Python-код или shell-команды не запускаются.
- Очередь и число рабочих потоков ограничены.
- Ошибки задач сохраняются в записи задачи, без раскрытия секретов.

## Проверка
Из корня репозитория:
```bash
PYTHONPATH=backend python -m unittest discover -s backend/tests -v
```
